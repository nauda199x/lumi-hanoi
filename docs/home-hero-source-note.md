# Homepage overview hero source

The homepage overview hero is derived from the verified Lumi Hanoi project source pack already used for content research.

- Source file: `2024.07.29 Lumi Elite - Agent Training.pdf`
- Source page: 23
- Treatment: the embedded clean panoramic rendering was reconstructed from its seven JPEG image strips, resized to 1600×900, and encoded as WebP for local delivery.
- Public asset: `assets/media/home/lumi-hanoi-overview.webp`
- Purpose: show the overall Lumi Hanoi tower composition and landscape at the top of the homepage instead of a street-level retail detail.

The public page does not hotlink the Drive/PDF source; it serves the optimized image from the repository.
